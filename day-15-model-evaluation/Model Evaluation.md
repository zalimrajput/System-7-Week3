### Key Concepts

| Concept | Purpose |
|---|---|
| Train-Test Split | Evaluates a trained model on unseen data. |
| Cross-Validation | Evaluates model performance across multiple data splits. |
| Accuracy | Measures the proportion of correct predictions. |
| Precision | Measures how many positive predictions are correct. |
| Recall | Measures how many actual positive cases are identified. |
| F1-Score | Balances precision and recall. |
| MAE | Measures the average absolute prediction error. |
| MSE | Measures the average squared prediction error. |
| RMSE | Measures prediction error in the target variable's units. |
| R² Score | Measures how well a regression model explains target variability. |
| Confusion Matrix | Summarizes correct and incorrect classification predictions. |
| ROC-AUC | Measures a classifier's ability to distinguish between classes across thresholds. |
